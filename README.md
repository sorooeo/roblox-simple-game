# Roblox Simple Game - Click the Blocks

A simple, easy Roblox game where players click blocks to earn points!

## Game Features
- **Click Blocks**: Click on blocks that spawn randomly to earn points
- **Score System**: Each block clicked = 1 point
- **Simple Gameplay**: Perfect for beginners to Roblox

## How to Play
1. Blocks will spawn randomly around the map
2. Click on a block to collect it and earn 1 point
3. Try to get the highest score!

## Installation
1. Download this repository
2. Open Roblox Studio
3. Create a new place
4. Copy the scripts from this repository into ServerScriptService
5. Run the game!

## Files
- `block_spawner.lua` - Spawns blocks randomly
- `block_click_detector.lua` - Handles clicking blocks and scoring
- `player_gui.lua` - Displays the player's score

Enjoy! 🎮
